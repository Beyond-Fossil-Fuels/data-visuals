BFF data visuals

Interactive graphics for the BFF website. Each one reads its numbers live from the public Google Sheet. Use Copy embed code to put a graphic on a web page, or Design mode to restyle it.

Sitewide auto-height script (add once)

This lets every embedded graphic grow or shrink to fit its content, with no scrollbars. Add it once to the website, for example with a header/footer code plugin. It can also go in the same Custom HTML block as an iframe.
